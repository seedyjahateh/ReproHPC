Read the units. Area is measured in square pixels here. Object-level CSVs also include calibrated area in µm² when calibration is available. Intensity ranges from 0–255; centroid coordinates use zero-based pixels.

Keep the precision. The view rounds numeric values for readability. An em dash means no value exists, as with mean area when an image contains no objects. CSV downloads retain the original values and are never filtered by this view.
