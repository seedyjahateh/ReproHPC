# FAIR and NIH DMS alignment worksheet

This is operational guidance for the synthetic demonstration, not an approved institutional DMS Plan. The PI/institution owns actual award commitments. Source: [NIH NOT-OD-26-046](https://grants.nih.gov/grants/guide/notice-files/NOT-OD-26-046.html); the 2026 pilot format applies to due dates on/after May 25, 2026.

| Plan element | Demo evidence / project decision needed |
|---|---|
| Maximum appropriate sharing | Share generated grayscale images, masks, measurements, calibration and provenance; confirm rights for project-specific data. |
| Timing | Deposit publication-supporting data by publication and other findings by award end; artifact owner records actual dates. |
| Duration | Repository/journal/institution obligations determine retention; record preservation owner. |
| Limitations | Synthetic demo has no participant restrictions. Project-specific limitations require reasons and the form's word limit. |
| Participant protections | Not applicable to generated images; protected-data deployment requires a separate institutional design. |
| Data types/repositories | Synthetic grayscale images and object measurements: Zenodo demonstration record. Prefer required domain repositories for actual research. |
| Genomic data sharing | Not applicable; reassess when covered genomic research is involved. |

FAIR release evidence: version DOIs and indexed metadata (F); HTTPS public artifacts and access terms (A); schemas, units, data dictionary and JSON-LD relationships (I); explicit licenses, provenance and scientific description (R). DOI publication and public-download reproduction remain mandatory release gates; a local archive or reserved identifier does not satisfy them.

Operations: inputs are immutable; retain work/cache for at least 30 days after a successful demonstration unless site policy requires otherwise. Archive cited code/SIF/data/reference/results durably. This work-retention default is not an NIH mandate. Keep generated results and validated manifests backed up separately from disposable task work. Record dataset volume and image dimensions, decoded storage estimate, backup location, repository costs, access conditions, artifact owner and retention obligations for each real project. Public export removes operational host paths and logs; never place confidential or participant information into demonstration inputs or metadata.
